opencode-museMuse subscription models, inside OpenCode

An OpenCode plugin that drives your Muse Code subscription through the official Muse CLI. Your login never leaves the CLI.

Get started
Compatibility record

Subscription stays in the CLI

The plugin talks to muse serve over its session protocol. It never reads your credential files, never relays keys, and never changes your billing mode.

Muse runs the agent loop

By default, Muse's own tools and system prompt do the work. OpenCode renders the result; it does not re-run tools or second-guess the model.

Pinned and probed

Every supported Muse CLI and OpenCode version is recorded with live probe evidence — catalog, text turns, rewind, approvals — not just declared.

Install ​

Add the published package to your project-level opencode.jsonc:

jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["opencode-muse@1.1.0"]
}

Then sign in once through the official CLI, restart OpenCode, and pick a Muse model:

sh
muse login

See Getting started for the fallback shim, PayGo billing, and OpenChamber notes. The snippet above always names the latest release — check Releases if yours differs. The package is also on npm.
